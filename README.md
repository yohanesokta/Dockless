# Ketertarikan

Dockless terinspirasi oleh project [OrbStack](https://orbstack.dev/) yang memangkas penggunaan resource berlebih agar penggunaan dapat jauh lebih efisien. Ini dapat meninggalkan kesan lambat di docker desktop.

**Dockless** ( dibaca: dokles ) melakukan pemuatan virtual machine yang minimimal sekali dengan size se minimal mungkin tapi tetap berfungsi sempurna!

> [!Important]
> Project ini dalam tahap pengembangan jadi gunakan secara experiment sebelum saya merilisnya secara resmi
